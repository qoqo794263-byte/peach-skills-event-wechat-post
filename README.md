# peach-skills-event-wechat-post

显示名：**peach skills - 活动公众号推文**

## 用途

根据活动信息为微信公众号写活动类推文初稿（预告、招募报名、活动回顾），含备选标题、摘要、正文、信息卡和 CTA 位置，并按检查清单自检。用户要写活动预告、报名招募、活动回顾公众号文章时使用；普通非活动公众号文章、小红书笔记、朋友圈文案、海报设计不使用。

## 安装

```bash
npx -y skills add qoqo794263-byte/peach-skills-event-wechat-post -g --all
```

## 使用

安装后，可以这样开始：

> 使用 $peach-skills-event-wechat-post 根据我给的活动信息写一篇公众号活动推文初稿。

## 运行依赖

- 支持 Agent Skills 的客户端
