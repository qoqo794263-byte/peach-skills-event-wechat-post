# 常见错误与发布前检查清单

初稿完成后逐项自检时读取。来源编号见 [sources.md](sources.md)。

## 8. 常见错误

1. 关键信息只放在海报图片里，或者藏在文末。[E1][E2]
2. 一篇里塞好几个 CTA（报名、关注、投票、转发……），读者不知道该做哪个。[E4]
3. CTA 写“点击这里”，看不出点了有什么好处。[E3]
4. 假的紧迫感（永远“最后 10 席”），会消耗读者的信任。[E2][E4]
5. 每篇都是“我们很激动地宣布……”，读者会慢慢不看了。[E5]
6. 标题和内容不匹配：标题党，或者干货藏在平淡的标题里。[X-xudaoai][X-spectredxxx]
7. 报名步骤太多（要关注、转发、截图、加微信、再填表）。[W1]
8. 回顾文章只写“圆满结束”，没有数据、照片和干货。
9. 二维码、链接、电话没有实测；时间、地点有错别字。[W4]
10. 一大段规则细则堆在开头，读者直接划走。[W2]

## 9. 可复用检查清单（发布前逐项打勾）

**标题与首屏**
- [ ] 标题写清了人群/收获/时间，没有夸大
- [ ] 准备了 2–3 个备选标题，选了最清楚的一个
- [ ] 首屏有：一句话亮点 + 主视觉 + 报名入口
- [ ] 摘要（分享卡片文字）单独写过，不是默认截取

**信息完整**
- [ ] 时间（日期 + 星期 + 时分）
- [ ] 地点（详细地址 / 线上入口）+ 交通
- [ ] 对象与门槛
- [ ] 费用与退改规则
- [ ] 名额与截止时间（真实）
- [ ] 福利领取条件
- [ ] 联系人
- [ ] 关键信息用文字写了，不只在图片里

**转化**
- [ ] 只有一个主 CTA，按钮文字说明了好处
- [ ] 报名入口出现了 3 次（首屏 / 中段 / 文末）
- [ ] 报名步骤不超过 3 步，写了预计用时和通知时间
- [ ] 有往期照片/数据/评价作为背书
- [ ] FAQ 3–5 条
- [ ] 设了渠道参数码，能统计来源

**排版**
- [ ] 正文 14–16px，行距 1.6 以上，每 300–400 字一个断点
- [ ] 颜色不超过 3 种，二维码清晰、有留白、写了“长按识别”
- [ ] 图片有版权，人物有授权
- [ ] 手机预览过，深色模式也检查过

**校对与发布**
- [ ] 二维码、链接、电话都实测过
- [ ] 时间、地点、嘉宾姓名核对了两遍
- [ ] 发布时间参考了后台数据
- [ ] 下一篇（提醒 / 回顾）已经排进日程
- [ ] 报名后的确认、提醒流程准备好了
