# 三类活动推文结构模板

判断出文章类型后读取对应小节。来源编号含义见 [sources.md](sources.md)。

## 0. 核心原则（先记住这 6 句）

1. **先让人一眼看懂“这是什么活动、跟我有什么关系”，再讲情怀。** 首屏要回答三件事：我能参加什么、能得到什么、去哪报名。[W2][W4]
2. **五要素必须齐全，而且放在前面：** 时间、地点、对象、费用、报名方式。最好做成一张“信息卡”。[W4]
3. **一篇文章只要一个主要行动**（报名 / 预约 / 扫码进群），报名入口在首屏、关键信息后、文末各放一次。[W2][W5][E2][E3]
4. **紧迫感必须是真的：** 真实的截止时间、名额、涨价节点。“别错过”这种话没用。[E2][E4][E5]
5. **标题要和内容对得上。** 内容很干、标题却看不出价值，就没人点；标题夸张、内容是广告，读者会取关。[X-xudaoai][X-spectredxxx]
6. **活动是一个系列，不是一篇文章：** 预告 → 详情/报名 → 催促 → 现场 → 回顾，每篇各有任务。[E4][E5]

## 1. 三类活动文章的结构模板

### 1.1 活动预告（Save the date / 官宣）
**任务：** 让人先记住日期、产生期待，不急着成交。[E5]

```
标题：【预告】{日期}｜{一句话亮点：嘉宾/主题/稀缺体验}
首屏：一句话说清“{谁}在{何时}{何地}做{什么}”，配主视觉海报
1. 为什么办这场（1 段，场景或痛点切入）
2. 最大的看点（1 个就够：重磅嘉宾 / 独家内容 / 首次开放）[E4]
3. 基本信息卡：时间（精确到时分）/ 地点或线上 / 面向谁
4. 下一步：“设提醒 / 关注 / 进预约群，报名开启第一时间通知”
5. 结尾：报名开放时间
```
参考写法：X 上的一条活动预告转述只写了核心信息——主题（Physical AI）、入场 18:30、圆桌 19:00、嘉宾列表，信息很密，不绕弯。[X-yangyang884r]

### 1.2 招募 / 报名（主要的转化文章）
**任务：** 让读者报名。推荐结构（综合 [W1][W2][W3]）：

```
标题：{人群} + {收获} + {时间/截止}，18–24 字以内为宜 [W1][W2]
首屏三件套：标题 + 一句话亮点 + 报名入口（二维码/阅读原文）[W2][W4]
① 导语 50–80 字：回答“我为什么要来” [W1]
② 亮点 / 你将获得（3 点，每点一句话 + 一张图）[W5]
③ 信息卡：时间｜地点｜对象｜名额｜费用｜门槛 [W4]
④ 流程 / 议程（时间轴或表格）
⑤ 信任背书：往期照片、数据、参与者评价、嘉宾介绍 [W3][E4]
⑥ 福利与紧迫感：早鸟截止、前 N 名礼品（必须属实）[E2]
⑦ 报名方式：不超过 3 步；写明“约 1 分钟填完 / 48 小时内通知结果” [W1][W2]
⑧ FAQ 3–5 条（能带娃吗？停车？下雨怎么办？可以退吗？）[W1]
⑨ 文末再放一次报名入口 + 联系人
```
文案公式：**场景（做什么）+ 利益点（对我有什么好处）+ 成本（我要付出什么）+ 行动（我该怎么做）。**[W3]

规则要写清楚：参与对象、次数限制、什么情况报名无效，提前讲明白，可以减少后面的纠纷。可参考 X 上一则社区活动说明的写法，它把参与对象、每天次数、禁止事项都单独列出来了。[X-dogewlfi]

### 1.3 活动回顾（复盘 / 战报）
**任务：** 留下记录、建立信任，为下一场蓄水。
```
标题：{活动名}回顾｜{一个最打动人的数字或瞬间}
首屏：一张最有氛围的现场大图 + 一句话总结
1. 数据战报：到场人数、城市、时长等，数字高亮 [W4]
2. 3–5 个精彩瞬间（照片组 + 一句话说明 / 金句）
3. 干货沉淀：嘉宾观点摘要（让没到场的人也有收获）
4. 参与者原话（真实反馈）
5. 致谢（嘉宾、场地、志愿者、合作方）
6. 下一步：下期预告 / 反馈问卷 / 进群码 [W4]
```
回顾文章最适合拿来“证明”活动好不好：下一场的招募文案里，直接引用这篇的照片和数据当背书。
