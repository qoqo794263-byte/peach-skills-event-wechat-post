# 系列发布节奏

用户问发布时间、系列规划，或需要在文末预告下一篇时读取。

## 7. 发布节奏（单场活动的推荐时间线）

参考英文活动邮件营销的序列做法 [E4][E5]，换成公众号节奏：

| 时间点 | 文章/动作 | 目标 |
|---|---|---|
| T-3～4 周 | 预告 / 官宣 | 记住日期，进预约群 |
| T-2～3 周 | 正式招募（详情 + 报名） | 主要转化 |
| T-2 周前后 | 嘉宾/亮点单独一篇 | 给读者一个新的报名理由 |
| 早鸟截止前 | 早鸟最后提醒（简短，一个 CTA） | 冲一波报名 |
| T-3 天 / T-1 天 | 最后召集 + 参会须知 | 补报名、提醒到场 |
| 活动当天 | 朋友圈 / 社群直播图 | 积累素材 |
| T+1～3 天 | 回顾文章 | 建立信任，为下一场铺垫 |

- 老参与者和新读者要区别对待（比如老参与者优先报名、专属早鸟价）。[E5]
- 发布时间：看自己后台数据和同行发文时间，别凭感觉。[X-MoonInAI] 定时群发时避开高峰拥堵时段。[W4]
- 有人在 X 上分享经验：持续、稳定地更新，是公众号进流量池的关键之一。[X-hyh1564069][X-MoonInAI]
