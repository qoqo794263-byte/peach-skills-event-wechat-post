# 写作技巧：标题、开头、信息卡、CTA、排版

写标题、首屏、信息卡和 CTA 时读取。来源编号见 [sources.md](sources.md)。

## 2. 标题技巧

- **写清楚，不玩文字游戏：** 活动通知类标题要让人一眼知道是什么活动；英文活动营销资料明确建议“避免 clever copy，人们只是扫一眼”。[E5]
- **常用公式：**
  - `{人群}注意！{日期}{活动}开放报名，限{N}席`
  - `{嘉宾}来{城市}了｜{主题}`（借知名嘉宾，对应 E5 的“{Speaker} is keynoting”）
  - `最后{N}小时｜{活动}报名今晚截止`（只在真的快截止时用）[E4]
  - 回顾：`{N}人、{N}小时，我们一起{做了什么}`
- **埋搜索关键词：** 想想目标用户会在微信里搜什么词，把这些词放进标题和摘要。[X-Missle8z]
- **拆解爆款、多试几个：** 研究同类账号已经跑出来的标题和发布时间，别闭门造车；先写 3 个版本再选。[X-MoonInAI][X-qihang_zeng6688][W2]
- **标题和内容要一致：** “标题都一样，内容就是广子”会让读者取关。[X-spectredxxx]

## 3. 开头钩子（前 3 行）

可选的几种开头：
1. **场景代入：** “周末除了躺着刷手机，你上一次认识新朋友是什么时候？”
2. **反常识 / 反差：** X 上拆解的爆款账号常用“反常识开头 + 结构化清单”。[X-qihang_zeng6688]
3. **结果先行：** 先亮出往期成果或数字，再讲怎么做到的（X 上有人分析长帖时总结的路数：“先甩反差结果，再给可复制框架”）。[X-lihu9048]
4. **直接给信息：** 对老读者，第一句就写“{日期}{地点}，我们又要见面了”。

不管用哪种，**第一屏都要能看到报名入口或者“往下看”的理由**。[W2]

## 4. 活动信息呈现（信息卡）

| 要素 | 写法要点 |
|---|---|
| 时间 | 年月日 + 星期 + 起止时分；线上活动注明时区 [E2] |
| 地点 | 详细地址 + 交通/停车 + 地图小图；线上写清平台和入口 [W4] |
| 对象 | 适合谁 / 不适合谁，门槛写明白 |
| 亮点 | 最多 3 条，每条一句话，有画面感 |
| 福利 | 早鸟价、礼品、证书等，写清条件和截止时间 |
| 费用 | 免费 / 金额 / 退款规则 |
| 报名方式 | 二维码（写“长按识别”）、阅读原文、小程序；步骤不超过 3 步 [W1][W4] |
| 联系人 | 微信号 / 电话 |

要点：关键信息用**文字**写，不要只放在海报图片里。图片加载不出来，信息就丢了。[E2]

## 5. 转化与行动号召（CTA）

- **按钮文字要说明点了能得到什么**，别写“点击这里”，改写“立即报名，锁定席位”“扫码预约提醒”。[E3]
- **同一篇只放一个主 CTA**，次要链接弱化处理。[E2][E4]
- **至少放 3 处：** 首屏、亮点/信息卡后、文末。[W2][W5]
- **降低顾虑：** 写清预计用时、什么时候通知、能不能退。[W2]
- **社会证明：** 往期照片、参与人数、真实评价。[W3][E4]
- **真实的紧迫感：** 早鸟截止、剩余名额，只写真实的情况，而且写具体：“周五 24:00 后恢复原价”比“别错过”有效。[E2][E5]
- **报名后马上确认：** PingCode 那篇文章建议在 72 小时内完成确认，作者称这样能降低缺席率。[W3]
- **让报名者帮你转发：** 报名成功后给一张专属“证书/入场卡”图，方便分享，这比只填表单多了一层传播。[X-MMoncici] 另可参考《读者凭什么替你转发？》一文。[X-Stanleysobest]
- **渠道归因：** 不同渠道用不同的参数二维码，就能知道哪里来的人报名多。[W2]

## 6. 排版与配图

- 正文 14–16px，行距 1.6–1.8；每 300–400 字设一个视觉断点（小标题、分割线、图）。[W2]
- 主色不超过 1 个、辅助色不超过 2 个；按钮和二维码用高对比色；二维码四周留白。[W4]
- 一屏讲一个重点；议程用时间轴，战报用高亮数字。[W1][W4]
- 互动组件（点击展开 FAQ、轮播往期照片、倒计时）2–3 处就够。[W4][W5]
- 配图用真实现场、真实的人，比素材图更让人信。[W5] 注意图片版权和肖像授权。[W4]
- 可以按类型（会议论坛、招新、抽奖、复盘等）做几套固定的排版模板，下次直接套用。[W4]
